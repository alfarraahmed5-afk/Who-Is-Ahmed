Ahmed AlFarra - portfolio site
==============================

Deploy: copy the contents of this folder into the root of the
Who-Is-Ahmed repository and let GitHub Pages serve it.
Everything is local. No CDN, no build step, no trackers.

Files
  index.html          the page
  assets/css          template stylesheet (accent recoloured to #24695C)
  assets/js           jquery + template scripts
  assets/webfonts     Font Awesome, bundled locally

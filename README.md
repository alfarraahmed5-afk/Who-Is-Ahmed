# Who Is Ahmed

Personal portfolio site for **Ahmed AlFarra** — urban planner, GIS and
location intelligence specialist based in Cairo, working across master
planning, spatial data pipelines and web GIS for government and
enterprise clients in the UAE and Egypt.

**Live:** https://alfarraahmed5-afk.github.io/Who-Is-Ahmed/

## About the site

A single static page, served straight from this repository by GitHub
Pages (`main` branch, root). No build step, no CDN, no trackers —
every asset is served locally.

Sections: selected work (planning and urban design, data systems and
platforms), experience, capabilities, education and contact.

## Layout

```
index.html          the page
assets/css          stylesheet (accent recoloured to #24695C)
assets/js           jquery + template scripts
assets/sass         sass sources for the stylesheet
assets/webfonts     Font Awesome, bundled locally
```

## Deploying

Push to `main`. GitHub Pages rebuilds from the repository root
automatically — there is nothing to compile.
